# 🧮 Digital Calculator (Python Tkinter)

A modern desktop calculator built using **Python** and **Tkinter**. It supports basic arithmetic operations, square, square root, percentage calculations, keyboard shortcuts, a live date & time display, and calculation history.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🟰 Instant calculation
- 🧹 Clear button
- ⌫ Backspace button
- √ Square Root
- x² Square
- % Percentage
- ⌨️ Keyboard support
- 🕒 Live Date & Time
- 📝 Calculation History
- 🗑️ Clear History

## 🛠️ Technologies Used

- Python 3
- Tkinter
- datetime
- math

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/python-calculator.git
```

### 2. Open the project folder

```bash
cd python-calculator
```

### 3. Run the program

```bash
python calculator.py
```

or

```bash
py calculator.py
```

## ⌨️ Keyboard Shortcuts

| Key | Action |
|------|--------|
| 0–9 | Enter numbers |
| + - * / | Operators |
| . | Decimal |
| Enter | Calculate |
| Backspace | Delete last character |
| Esc | Clear display |

## ⚠️ Note

This is a **desktop application** built with **Tkinter**.

It works on Windows, macOS, and Linux with a graphical desktop environment.

It **will not run directly in GitHub Codespaces or a web browser** because Tkinter requires a graphical display.
